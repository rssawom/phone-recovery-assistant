🤖 Android Recovery

For an Android phone, use the manufacturer's official recovery procedure.

  1. Connect the phone to your computer with a USB cable.
  2. Back up important data if you still have access.
  3. Use the manufacturer's official recovery instructions.
  4. If a factory reset is required, read the warning carefully.
  5. After resetting, complete the normal Android setup.
  6. If Google verification appears, use the Google account previously associated with the phone.

This assistant does not bypass Google verification, screen locks or other security protections.

🍎 iPhone Recovery

For an iPhone, use Apple's official recovery procedure through a compatible computer.

  1. Connect the iPhone to the computer using a USB cable.
  2. Back up your information whenever possible.
  3. Use Apple's official recovery process.
  4. Follow the instructions shown by the computer.
  5. If the device is erased, complete the normal setup.
  6. Use the Apple Account previously associated with the device when activation requires it.

This assistant does not bypass Activation Lock, passcodes or Apple security protections.
